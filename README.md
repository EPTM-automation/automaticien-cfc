# Électrotechnique · Commande électrique · NIBT

Outils interactifs pour apprentis automaticiens CFC.

- **Électrotechnique** : loi d'Ohm, circuits série, parallèle et mixtes, résistance de ligne et chute de tension, transistor NPN en commutation, résistance série d'une LED, diodes à jonction et Zener (continu et alternatif), code couleurs des résistances.
- **Commande électrique** : en préparation.
- **NIBT** : en préparation.
